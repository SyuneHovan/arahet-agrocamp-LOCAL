# 🌾 Վերնաշեն — Ագրոարկած

3-օրյա ագրոճամբարի **mobile-first թիմային ինտերակտիվ ներկայացում**։

## Բաժիններ
- Գաղափար և նպատակ
- Գյուղական փորձառություններ
- 3-օրյա ժամանակացույց և սնունդ
- Ֆինանսական հաշվիչ (մասնակիցներ, գին, փոփոխական ու ֆիքսված ծախսեր)
- Անձնակազմ, անվտանգություն, checklists
- Գործարկման օրացույց և տարածում

## Օգտագործում
Կայքի աջ վերևում սեղմեք **«Խմբագրել»**, հետո սեղմեք փոփոխվող տեքստին։ Սեղմեք **«Պահպանել»**։ Տվյալները պահվում են միայն տվյալ սարքի browser-ի localStorage-ում։ Թիմի տարբեր սարքերի միջև ավտոմատ համաժամեցում **չկա**։ Ֆինանսական հաշվիչը և checklist-ը նույնպես տեղային են։

## Vercel
Կայքը սովորական ստատիկ HTML է. framework, build command կամ environment variable պետք չէ։ Vercel > Add New Project > Import Git Repository > `SyuneHovan/vernashen-agrocamp` > Framework Preset: **Other** > Deploy։

## Նշում
Գները, շահույթը և ճամբարի պայմանները նախնական են։ Մինչև վճարովի գրանցումը անհրաժեշտ է հաստատել անվտանգ կացություն, պատասխանատուներ, տրանսպորտ, ծնողական համաձայնություններ և կիրառելի իրավական պահանջներ։
