# Արահետ — ներքին աշխատանքային կայք

Պահոց՝ `SyuneHovan/arahet-agrocamp-LOCAL`։ Կայք՝ https://arahet-agrocamp.vercel.app/ ։ Հանրային կայքը առանձին է։

## Հաստատված տվյալներ
2026 հոկտեմբերի 27–29, Ելփին, 12–16 տարեկան, 29,000 դրամ, առավելագույնը 25 մասնակից։ 2026 հոկտեմբերի 19-ի դրությամբ՝ 2 գրանցված, 23 ազատ տեղ։ Հավաք՝ հոկտեմբերի 27-ին 08:30, Սասունցի Դավթի կայարանի հրապարակում, մեկնում՝ 09:00։ Վերադարձի մեկնում Ելփինից՝ հոկտեմբերի 29-ին մոտ 16:30։

Կազմակերպիչներ՝ «Բարձունք» կրթական շարժում ՀԿ և «Արահետ» լեռնարշավային առաջնություն։ Գրանցումներն ու ծնողական համաձայնագրի ձևը պատրաստ են։ Տրանսպորտը, գիշերակացը, թիմի պարտականությունները, բյուջեն և գնումներն ընթացքի մեջ են։

## Բաժիններ
Գաղափար, փորձառություններ, ծրագիր և սնունդ, ֆինանսական սցենարների հաշվիչ, թիմ և անվտանգություն, պատրաստության ամփոփում։ Ծրագրի մանրամասները, ծախսերը և թիմի կազմը նախնական են։ Աշխատանքի պլանավորման ու տարածման checkbox-ներով բաժինը հաջորդ փուլի համար է։

## Տեղային սևագրեր
«Խմբագրել» գործառույթն ու հաշվիչի սցենարը պահվում են միայն տվյալ դիտարկիչում։ Թիմային համաժամեցում չկա։ Հաստատված տվյալներն ու պատրաստության վիճակները փոփոխվում են կոդում։ Գրանցվածների թիվն ինքնաշխատ չէ։ Նոր տվյալների տարբերակն օգտագործում է առանձին պահոցային բանալի, որպեսզի նախկին սարքային սևագրերը չփոխարինեն նոր հաստատված տեղեկություններին. հին տվյալները չեն ջնջվում։

## Գործարկում
Ստատիկ HTML/CSS/JavaScript կայք է՝ առանց հավաքման քայլի։ Տեղային դիտում՝ `py -m http.server 5173`։ Vercel-ի գործող նախագծին կապված է այս պահոցի `main` ճյուղը։
